# איזו שפה אתם דוברים? · NGG · NEXUS 2026

שאלון אפיון קצר למובייל (12 היגדים) שמחזיר לכל משתתף את שפת האם שלו ואת השפה החלשה שלו, מתוך ארבע השפות של מודל NGG להטמעת AI. אתר סטטי בעברית וב-RTL. אין בו שרת, הרשמה או שמירת נתונים.

מסמך המקור הוא `CONTEXT.md`. ההחלטות שהתקבלו בהמשך מתועדות בסעיף "סטיות מוסכמות".

## הרצה

```bash
npm install
npm run dev          # פיתוח: http://localhost:5173
npm run build        # בנייה ל-dist/ (נתיב בסיס יחסי, עובד בכל דומיין)
npm run preview      # הגשת ה-build
npm test             # בדיקות הלוגיקה המקורית (node --test) ובדיקות היחידה (Vitest)
npm run test:e2e     # בנייה + בדיקות דפדפן (Playwright, Chromium, 390×844)
```

את תוצאות ההשוואה הוויזואלית אפשר לראות ב-`e2e/__report__/`: הרפרנס, הצילום שלנו ומפת ההבדלים, זה לצד זה.

## פריסה (GitHub Pages)

- **`.github/workflows/deploy.yml`:** בכל push ל-`main` מריץ את בדיקות הלוגיקה והיחידה, typecheck ו-build. אם הכל עובר, הוא מפרסם את `dist/` ל-GitHub Pages. אפשר גם להפעיל אותו ידנית מלשונית Actions.
- **`.github/workflows/ci.yml`:** בכל pull request מריץ את כל הבדיקות, כולל בדיקות הדפדפן. תמונות ההשוואה מצורפות להרצה כ-artifact בשם `e2e-report`.
- **למה בדיקות הדפדפן לא חוסמות את הפריסה:** השוואת צילומים יכולה להשתנות מעט בין מכונות. לא נרצה שהבדל של פיקסלים יעכב תיקון תוכן דחוף ביום הכנס. הן רצות על כל PR, וחובה לעבור עליהן לפני המיזוג.

**הגדרה חד-פעמית:**
1. Settings ← Pages ← Source: לבחור **GitHub Actions**.
2. למזג את הענף ל-`main`. הפריסה הראשונה תרוץ אוטומטית, והאתר יעלה ב-`https://ngg-global.github.io/NGGLanguage/`.
3. **דומיין של NGG:** ב-DNS מוסיפים רשומת `CNAME` מתת-הדומיין (למשל `nexus.nggconsult.com`) אל `ngg-global.github.io`. אחר כך ב-Settings ← Pages ← Custom domain מזינים את תת-הדומיין ומסמנים **Enforce HTTPS**. אין צורך בקובץ CNAME בריפו.
4. מעדכנים את `ui.share.link` ב-`content.json` לכתובת הסופית, ועושים commit. הכתובת תופיע על כרטיס השיתוף.

**שינוי תוכן:** עורכים את `content/content.json`, ועושים commit ל-`main` (ישירות או דרך PR). האתר מתעדכן תוך כדקה–שתיים.

**חזרה לגרסה קודמת:** Actions ← ההרצה המוצלחת האחרונה ← Re-run jobs. אפשר גם לעשות `git revert` ו-push.

## זרימה

`Boot` ← `S1 פתיחה` ← `S2 מסגור` ← `S3 ×12` ← `S5 שובר שוויון (רק כשיש שוויון בראש)` ← `S6` ← `R תוצאה`

- **מעבר בין מסכים:** הכפתור "בואו נתחיל" באנימציית הפתיחה מוביל ל-S1.
- **"חזרה":** מ-S2 חוזרים ל-S1 בלי לנגן שוב את הפתיחה. משאלה 1 חוזרים ל-S2. משאר השאלות חוזרים לשאלה הקודמת, והתשובה שנבחרה בה מסומנת.
- **S5:** אין בו "חזרה", כמו בצילום.
- **"מילוי מחדש":** דורש לחיצה שנייה תוך 3.2 שניות, ומאפס הכל ל-S1.

## עריכת תוכן

- **מקור הטקסטים:** כל טקסט שמוצג למשתמש נטען מ-`content/content.json`, ואין טקסט קשיח בקוד.
- **הטמעה בבנייה:** הקובץ מוטמע בזמן הבנייה. אחרי שינוי מריצים `npm run build` ופורסים מחדש.
- **ולידציה:** אם חסר מפתח, האפליקציה והבדיקות נכשלות עם רשימת המפתחות החסרים. מפתח חסר לא יוצג אף פעם כ-"undefined".
- **מפתחות שנוספו כטיוטה** (מאושרים לטיוטה, ממתינים לאישור נוסח):
  - `ui.meta`: כותרת הדף ותיאורו.
  - `ui.brand`: NEXUS, 2026 ו-alt של הלוגו.
  - `ui.boot`: הכותרת, הכפתור והמונה של אנימציית הפתיחה.
  - `ui.listSeparator`.
  - `ui.map.aria`: תיאור המפה לקוראי מסך.
  - `ui.share.fileName`, `ui.share.shareTitle` ו-`ui.result.toastError`.

## סטיות מוסכמות מ-CONTEXT.md

1. **אנימציית הפתיחה** (`src/boot/`) נבנתה מחדש מ-`NGG_Boot_Animation.html`, לפי ההחלטה שהיא גוברת על הקונטקסט:
   - **מה נשמר:** אותן סצנות, אותם תזמונים, אותן עקומות ואותה גאומטריה. משך 7.7 שניות, ונגיעה באמצע קופצת לסוף.
   - **צבעים:** הותאמו לטוקנים. האינדיגו והלבנדר הוחלפו ב-electric, sky, mist ו-ice, והוורוד במגנטה.
   - **גופן:** Heebo במקום IBM Plex Sans Hebrew. המונה "SYS.BOOT / NEXUS 2026" נשאר ב-IBM Plex Mono.
   - **כפתור:** בסגנון הכפתור הראשי של הממשק, עם טקסט ‎#00002C שעומד ב-AA.
   - **הוסר:** הסאונד, ה-runtime של Claude Design ופאנל העריכה.
   - **משקל:** שכבות הלוגו כווצו מ-514KB ל-29KB.
2. **`--white: #FFFFFF`** נוסף ל-`tokens.css`, כי הצילומים משתמשים בו לטקסט ההיגדים ולתוויות.
3. **כרטיס השיתוף** מציג "+ להביא איתי" גם בתוך המפה (בצילום כתוב שם "איתכם").
4. **תנועה:** באב-טיפוס מונפשים `box-shadow`, `background-position`, `left/top`, `width` ו-`letter-spacing`. כאן הם מומשו רק עם transform, opacity, clip-path ו-stroke-dashoffset, לפי סעיף 7. אנימציית ה-letter-spacing של שם שפת האם הושמטה.
5. **מסך הפתיחה (S1):** לבקשת NGG הוסרו שורת העובדות ("כ-3 דקות", "בלי הרשמה", "שום דבר לא נשמר") ושורת "מיפוי רפלקטיבי לשיחה, לא מבחן". שני המפתחות נמחקו גם מ-`content.json`, והכפתור "מתחילים" ירד לתחתית המסך. ההבהרה המלאה נשארת במסך התוצאה.
6. **שפה שנייה קרובה:** כשמוצגת השורה "ובקרבה", הרווחים בראש מסך התוצאה מצטמצמים בכ-14px, כדי ש"שמירת המפה" יישאר גלוי בלי גלילה ב-390×844 (קריטריון 2).

## פרטיות ורשת

- **אין שמירה:** אין localStorage, cookies, IndexedDB או Service Worker. התשובות נשמרות בזיכרון בלבד.
- **אין רשת אחרי הטעינה:**
  - כל התמונות וכל הגופנים נטענים מראש בטעינה הראשונה, וכרטיס השיתוף נוצר בלי אף בקשה.
  - ב-build מוגדר `Content-Security-Policy` עם `connect-src 'none'`.
  - בדיקת e2e מוודאת שאין אף בקשה אחרי `load`, לאורך כל הזרימה וגם בייצוא.
- **גופנים מקומיים:** Heebo (Hebrew + Latin) ו-IBM Plex Mono נשמרים באתר עצמו, ואין פנייה ל-Google Fonts.

## כרטיס השיתוף

- **ציור:** PNG בגודל 1080×1920, מצויר ישירות ב-Canvas 2D (`src/share/card.ts`) בצד הלקוח.
- **שמירה:** במכשירי מגע נפתח גיליון השיתוף של המערכת (Web Share API עם קבצים). במחשב, או כשאין תמיכה, הקובץ יורד ישירות.
- **הכנה מראש:** הקובץ מוכן כבר בזמן חשיפת התוצאה, כך שגיליון השיתוף נפתח מתוך הלחיצה עצמה. iOS Safari דוחה שיתוף שמתעכב יותר מדי אחרי הלחיצה.

## בדיקות

- **`npm test`:**
  - `logic/scoring.test.mjs`: 6 בדיקות, הקובץ המקורי.
  - בדיקות יחידה (19): מכונת המצבים, גאומטריה זהה לנוסחת קו האור של האב-טיפוס, שלמות התוכן ומילים אסורות, ומודל כרטיס השיתוף.
- **`npm run test:e2e`:**
  - **התאמה ויזואלית:** לכל המסכים מול `reference/`. ההבדלים הם בין 0.0% ל-0.4% מהפיקסלים, והסף הוא 1.5%.
  - **זרימה והתנהגות:** חזרה, כיווני תנועה, אורך S6, איפוס ופוקוס.
  - **מקרי קצה:** שוויון של 2, 3 ו-4 שפות, 2–3 שפות חלשות, פרופיל מאוזן, שפה שנייה קרובה ו-reduced motion.
  - **"שמירת המפה" גלוי בלי גלילה:** בכל 24 הצירופים של שפת אם, שפה חלשה ושפה שנייה קרובה.
  - **רוחבים:** 360, 430 ודסקטופ.
  - **פרטיות:** אין רשת ואין שמירה.
  - **החלפת מונחים:** build נפרד שבו שמות השפות שונו.
  - **כרטיס השיתוף:** בהשוואה לרפרנס.

## פתוח, לא הוחלט

- **נוסח התוכן:** ממתין לאישור. זה כולל את המפתחות שנוספו כטיוטה.
- **`ui.share.link`:** עדיין `[קישור קצר]`, ומוצג כך על הכרטיס. צריך להחליף אותו לפני הכנס, יחד עם הדומיין וה-QR.
- **שתי שפות חלשות ומעלה:** האם להצמיד את "שמירת המפה" לתחתית המסך. כרגע הוא לא מוצמד, כמו בצילום 10.
- **בדיקה במכשירים אמיתיים:** iOS Safari ו-Android Chrome. צריך לבדוק שיתוף והורדה של ה-PNG, רטט (לא נתמך ב-iOS) וביצועים במכשיר בינוני. הבדיקות כאן רצות ב-Chromium בלבד.
